# javascript-2-assignment

A front-end social media application created for the JavaScript 2 Course Assignment.

The application uses the Noroff API and allows users to register, log in, create and manage posts, search for content, and interact with other user profiles.

## Features

- Register a new user
- Login and logout
- View a feed of posts
- View individual posts
- Create posts
- Edit own posts
- Delete own posts
- Search for posts
- View own profile
- Search for other profiles
- View posts from other users
- Follow and unfollow users

## Technologies Used

- HTML
- CSS
- JavaScript
- ES6 Modules
- Noroff API

## Design

The application uses a simple mobile-first design.

I chose to keep the styling basic and focus primarily on JavaScript functionality, API integration and usability. The interface uses consistent colors, buttons and post cards across the different views.

## Running the Project

1. Clone the repository.
2. Open the project in VS Code.
3. Run the project using Live Server or another local development server.
4. Register a user or log in with an existing Noroff student account.

## API

This project uses the Noroff API v2 for authentication, posts and social profile functionality.
